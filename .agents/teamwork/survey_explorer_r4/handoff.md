## 2. Logic Chain

1. **Design System Unification (P17):**  
   From Observation 2, seller views rely on Tailwind classes generated by the inline script (`bg-surface`, `bg-brand-amber`, `font-heading`, `rounded-custom`, `bg-surface-container-*`), while customer views rely on compiled Tailwind classes from `app.css`. Because Tailwind CSS v4 is used via `@tailwindcss/vite`, adding CSS variables in `@theme` in `resources/css/app.css` creates standard utility classes for both palettes simultaneously. Replacing the CDN in `layouts/seller.blade.php` with `@vite` will allow all seller views to compile through Vite without breaking any existing styling.
2. **Interactive Components (P18, P19, P34, P37, P38):**  
   From Observation 3:
   - `Notification` model and table already exist. Querying unread notifications in `nav-user.blade.php` using `Notification::where('user_id', $currentUser->id)->whereNull('read_at')->count()` allows replacing "3 New" and conditionalizing the notification dot cleanly.
   - Guarding cart popover hover with `window.matchMedia('(hover: hover)').matches` stops `@mouseenter` from executing on mobile devices, restoring natural tap-to-navigate behavior.
   - Removing `user-scalable=no` from all 4 views directly satisfies WCAG 2.1 Criterion 1.4.4.
   - Adding the currency dropdown button into `components/footer.blade.php` activates the existing `setCurrency()` and `applyCurrency()` functions without new JavaScript dependencies.
   - Storing `node._originalText` on text nodes during DOM walking allows instant restoration when `langCode === 'en'`, eliminating `window.location.reload()`.
3. **Navigation & Links (P20, P21, P22, P29, P30, P36):**  
   From Observation 4:
   - Creating `/privacy`, `/terms`, `/return-policy` routes and wiring them to footer links satisfies the mandatory Acceptance Criteria test.
   - Aligning footer "Deals" to `filter=deals` ensures that `request('filter') === 'deals'` triggers the active state in `nav-user.blade.php`.
   - `components/nav-user.blade.php` already contains full guest authentication controls (`@else` with "Sign in" / "Sign up"). Removing the delegation lines (16–20) enables the rich navbar (categories, search, guest cart) across all pages, including `index.blade.php`.
   - Updating popular search chips in `index.blade.php` to matching seed terms (`Mechanical Keyboard`, `Leather Bag`, `Headphones`, `Silk Scarf`) prevents immediate 0-result search impressions.
   - Switching mega-menu links in `nav-user.blade.php` to `['category' => $slug]` activates the indexed category filter in `ProductController.php`.
